# ModernKnockBack 2.7.0

新增游戏内 KB 参数菜单。管理员输入 `/kb gui` 后，菜单根据当前模式分别编辑 Classic 或 Modern 配置。

- 可选择全局默认值或单独 profile，并按击退、限制/动量、鱼竿分类浏览。
- 数值参数显示用途说明、范围和调整步长；开关和模式选项可直接切换。
- 每次修改都会校验完整配置、持久化到当前模式的 `profiles.yml` 并即时应用。无效修改会保留原配置；修改全局默认值时，profile 的显式覆盖值不变。
- 菜单阻止物品移动和拖拽；模式切换后旧菜单不会写入另一模式的配置。
- 注册 `/kb` 为主命令别名，保留 `/mkb` 和 `/modernkb`。

验证：自动化测试通过后使用 `mvn package` 生成发布 Jar。支持 Minecraft 1.21.11 / Java 21+。
