# Classic 视角、鱼钩与同步（2.0.6）

只修改 ModernKnockBack。这次确认的问题可以在插件内处理，不需要改 Leaf、ASPaper 或 Folia 核心；已有配置和 KB 数值保留。

## 受击视角

高版本受击包携带伤害方向，客户端据此决定镜头倾斜方向。classic 对接收玩家本人的 `ClientboundHurtAnimationPacket` 创建角度为 0 的副本，对应旧版固定受击倾斜；继续播放受伤动画，不旋转玩家实际 yaw/pitch，也不发送位置纠正或传送。

其他实体的受击包不修改，modern、排除玩家和移除处理器后原样通过。组合包保留顺序和其他内容，不修改多个接收者共享的原包。重生后更新本人的实体 ID。鱼竿补发动画使用 Bukkit 的 `-90°` 参数，对应核心实际发送的 `0°`。

这是固定晃动，不是关闭全部受击晃动。若现象是实际准星朝向改变、位置被拉回或反作弊回弹，应继续记录对应的位置/旋转纠正包；本次修复不能证明那些现象也来自受击动画。

## 鱼钩附着与视线

成功流程为：一次真实零伤害投射物命中 → 一次经典 KB → 最终速度事件未取消且本次命中仍有效 → 受击红闪动画与单次声音 → 立即发送速度 → 仅对受击玩家隐藏鱼钩 → 原生挂钩。全部在同 tick 内完成，不等待动画结束，不定身。

2.0.5 已使用能产生红闪的 `playHurtAnimation(-90f)`，但在速度发送和挂钩之后才播放，隐藏事件重入还可能使后续反馈被跳过。2.0.6 将反馈移至最终速度事件确认之后、速度发包之前。该 API 向跟踪目标的玩家及目标本人发送受击动画包；1.21.11 客户端由此设置受击动画时间，实体渲染使用此状态显示红闪。无需为了变红增加真实扣血，也不补发旧版实体状态包。第一人称本人主要看到固定受击晃动，第三人称及旁观者能观察身体红闪；实际呈现仍需客户端复测。

用 `Player.hideEntity(plugin, hook)` 隐藏被钩者看到的钩子；出杆者和其他旁观者仍能看到钩子与鱼线。原生挂钩负责跟随目标位置，不在玩家面前人工回弹，不用逐 tick 传送钩子或玩家来模拟附着。

取消、免疫、击退失败的接触不挂钩；保留已接触标记并仅向下落，不再反向侧弹。成功挂住的钩子也不能再次击退，同一枚钩在保护期结束后仍然失效。默认连续杆、竿接刀的 10 tick 保护不变。

收杆时在原生拉回及其客户端状态包之前取消拉回并移除鱼钩。模式切换、重载、距离/寿命限制、退出、重生和正常停服负责清理；原生实体移除清除隐藏记录，不在移除前重新显示造成闪烁。

Folia 只在同时拥有鱼钩和受击者的区域内隐藏、附着；隐藏事件重入后再次检查区域和本次命中。外区不补打，不在禁用后创建调度任务。跨区域热卸载不作为支持的更新方式，请正常停服更新。

## Leaf 与 KnockbackSync

Leaf 的 `flush-location-while-knockback-player` 会让一次原生近战流程同步派发两次 `PlayerVelocityEvent`：一次在 `Player.causeExtraKnockback`，另一次在它立即调用的 `ServerEntity.sendChanges` 中。旧版本首次保护后已消费记录，第二次同步插件可以再次改变实际速度。

2.0.5 读取该选项，并检查真实调用栈，只为上述第二次同步事件保留一次保护资格。第二次重新捕获当时实际运动状态，不复用第一包向量；重新检查事件取消、模式、排除、原伤害/KB和命中身份。普通 tracker tick、插件主动刷 tracker、后续 tick 和新命中不能借用该资格。未改核心选项。

该修复解决已复现的错误速度改写；它不等于降低了实测网络延迟。网络 RTT、服务器 tick 耗时、客户端插值和反作弊位置修正仍需真实联机确认。

## 生硬感与参数

当前 classic 默认水平/垂直旧动量保留率为 0，每击直接得到指定目标速度，以满足固定力度的既有要求。地面/空中 Y 不同、有效 jump reset 保留半动量，也会带来实际状态差异。没有发现插件把一次 KB 分成多 tick 发送；本次继续立即计算和发送。

先用已有配置复测上述修复，避免同时改变多个因素。如果疾跑瞬间推力仍过强，可单独将当前使用 profile 的 `classic.sprint-horizontal` 从默认 `0.5` 试调为 `0.3`，其余值保持不变。显式 `y-limit-enabled: true` 且 `vertical-after-limit: 0` 会截断达到高度后的抬升，若仍使用旧配置应一并核对。非零动量保留会改变最终方向，不适合在排查侧偏时未经对照直接启用。

## 联机复测

1. 双方平地互打，比较正面、左右绕圈和跳跃暴击：本人保留固定受击晃动，实际准星朝向不被插件改写。
2. 鱼钩成功命中移动玩家：出杆者或第三人称受击者观察身体红闪及紧接着的击退；出杆者看到附着，被钩者看不到钩子挡脸；收杆不拉回。
3. 快速连杆、竿接刀、免疫及保护区取消：不强制受击，同一钩不产生第二次 KB。
4. 在 Leaf 立即同步选项开/关两种环境，以及 ASPaper、Folia 上，与实际 KnockbackSync 和反作弊对打。
5. 对照双方真实 RTT、抖动与服务器 tick 耗时，再评估是否仍有等待、回弹或突然加速。
