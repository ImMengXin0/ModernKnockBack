# ModernKnockBack 2.8.0

整合 `modernknockback-ui.zip` 的界面更新，重新构建适用于 Minecraft 1.21.11 / Java 21+ 的发布包。

- `/kb gui` 使用统一配色、背景、分类图标和分页信息；参数显示当前值、范围、调整步长、范围位置条及配置字段名。
- 命令成功、错误和等待提示统一为中文格式；`/mkb status` 分组展示服务器信息、同步策略、击退统计及 Classic 设置。
- `/mkb help` 展示命令帮助并支持 Tab 补全；保留 `/mkb`、`/kb`、`/modernkb` 别名及 `/kbtest` 模式命令。控制台输出会移除颜色控制码。
- 每次打开或操作菜单重新检查管理员权限；撤权后关闭旧菜单，防止继续修改配置。重载删除 profile 或切换模式后，旧菜单返回当前列表。
- 菜单按钮只响应普通左键，拦截右键、Shift、数字键、双击、拖拽及背包物品移动，避免误改参数。

此次整合不修改 Classic / Modern 击退算法、攻击节奏或默认 KB 数值，不新增配置项。README 继续只提供参数参考和命令帮助。

验证：完整 Maven 构建及 380 项自动化测试通过，包含新增的 7 项菜单交互回归，覆盖模式隔离、权限撤销、profile 删除、模式切换、非左键操作和物品移动拦截。菜单的字体、颜色与屏幕布局仍需在客户端确认；未部署到运行中的服务器。

升级：用 `ModernKnockBack-2.8.0.jar` 替换旧 Jar 并正常重启，保留现有配置。发布附件包含插件 Jar、干净源码 ZIP 和 SHA256 校验文件。
