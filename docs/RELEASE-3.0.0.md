# ModernKnockBack 3.0.0

新增 KB Profiler，为 Minecraft 1.21.11 / Java 21+ 提供采集、统计与离线网页分析。

- `/kbtest profiler open` 开始检测并识别当前模式；`stop` 停止并导出报告；`status` 查看采集状态；`report` 再次显示本次运行期间最近生成的报告位置。命令需要 `modernkb.admin` 权限。
- 同时支持 Classic、Modern，并单独标识 Classic 中使用 Modern 攻击方式的物品。记录配置档、击退类型、攻击状态、原始事件向量、计算结果、本插件写入值、MONITOR 阶段观察值、相关速度事件与受击后三 tick 的短时位移。
- 报告包含水平 / 垂直时间线、向量分布与对照、Ping 散点与分组、处理耗时和速度事件观察间隔；支持按模式、配置档、类型及玩家筛选，查看单次受击详情并导出 JSON。
- 保存完整有效参数及说明、插件环境和 KnockbackSync 状态。切换模式、重载或 GUI 改参时追加参数快照，便于比较不同设置；取消、后续改写和轨迹中断均有标识。
- 实体观察在所属区域执行，适配 Folia 调度；报告在后台生成。每次采集最多 15 分钟或 10000 条 KB 事件，达到上限自动导出，插件正常卸载时也会保存进行中的检测。无需新增配置项。

HTML 保存至 `plugins/ModernKnockBack/profiler/kb-<会话ID>.html`，包含全部图表代码与数据，无需联网或额外网页服务。命令返回服务器本机文件链接；远程管理服务器时，请下载 HTML 后用浏览器打开，该链接不是公网访问地址。

分析基于服务端观测：Classic 目标速度、KB 事件增量和速度事件分别展示；同一受击者三 tick 内的速度事件只作为关联候选。Ping 和事件间隔不能证明真实丢包率、客户端收包时间或网络问题的因果关系。

验证：3.0.0 已通过完整 Maven clean verify 构建，419 项自动化测试全部通过；离线网页已验证空报告和 10000 条样本及筛选、参数搜索、分页和详情交互。

升级：使用 `ModernKnockBack-3.0.0.jar` 替换旧 Jar 并正常重启，保留现有配置。发布附件包含插件 Jar、干净源码 ZIP 和 SHA256 校验文件。README 继续仅提供参数参考和命令帮助。
