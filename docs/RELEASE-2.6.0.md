# ModernKnockBack 2.6.0

Classic 传统击退忽略下界合金护甲自带的抗击退。相同命中状态和配置下，穿一至四件原版下界合金护甲不会再削弱水平与垂直推力，无需新增或修改配置。

- 适用于 Classic 近战、疾跑、击退附魔，以及由 Classic 向量处理的鱼竿、弓箭等投射物。
- 按命中时实际装备和属性识别四个护甲槽位的原版抗性修饰符，仅在本次 Classic 计算中排除；不删除实体属性或修改物品。
- 保留基础属性与其他自定义抗性。按属性加法与乘法顺序重新计算，避免原生属性已被上限截断时直接相减导致错误。
- Modern 模式，以及 `classic/item.yml` 指定的现代武器例外，继续使用原生抗击退规则。原有 `classic.respect-resistance: false` 仍可关闭其他抗性的主动缩放。
- 保留 Classic 单次击退、防叠击、jump reset、CPS 密度下限与速度发送保护，并将新增计算类纳入启动预加载。

验证：365 项自动化测试通过；全部源码通过 Leaf 1.21.11-178、ASPaper 本地 1.21.11、Folia 1.21.11-14 实际运行库编译与离线探针。新增检查涵盖四种下界合金护甲的真实修饰符、穿脱装备、地面/空中/疾跑/投射物、其他抗性及乘法上限、单次速度发送和 Modern 隔离。尚未进行目标服真人对打验证，详见 [验证记录](VERIFICATION.md)。

升级：正常停服，将旧 Jar 替换为 `ModernKnockBack-2.6.0.jar` 后启动；保留原有配置和模式选择。支持 Minecraft 1.21.11 / Java 21+。
