# ModernKnockBack 2.3.0

classic 模式新增 Minecraft 1.8 斧头基础伤害适配，解决现代斧头在无蓄力攻击下基础伤害过高的问题。适用于 Minecraft 1.21.11 / Java 21+。

## 更新内容

`classic/combat.yml` 新增默认开启、升级自动补全的配置：

```yaml
legacy-axe-damage: true
```

标准玩家基础攻击力为 1，使用未设置自定义攻击伤害属性的斧头时，基础总伤害如下（2 点伤害为 1 颗心）：

| 斧头 | 现代基础总伤害 | classic 开启适配后 |
| --- | --- | --- |
| 木斧 / 金斧 | 7 | 4 |
| 石斧 | 9 | 5 |
| 铁斧 | 9 | 6 |
| 钻石斧 | 9 | 7 |

- 使用插件自己的临时攻击属性修正，在原版计算暴击、力量、附魔和护甲之前生效；最终扣血仍由核心及其他伤害插件决定。
- 切换武器、关闭配置、切回 modern、排除玩家或正常停用时移除自身修正，避免影响其他武器。
- 铜斧、下界合金斧，以及显式设置了自定义攻击伤害属性的物品保留原值。
- 保留 2.2.0 的击退、鱼竿、防叠击、jump reset、CPS 密度和旧版命中反馈。旧配置构造器继续提供兼容入口。

## 升级

正常停服，用 `ModernKnockBack-2.3.0.jar` 替换旧 Jar，保留插件数据目录后启动。使用 `/mkb status` 核对版本；classic 加载时会补全新配置。若要保留现代斧头伤害，将 `legacy-axe-damage` 设为 `false`，再执行 `/mkb reload`。
