# 2.0.5-r4：恢复 2.0.4 战斗与鱼竿实现

按用户实服反馈回退，基准为 Git 标签 `v2.0.4`，提交 `9dffb7d`。本次 `src/main/java/` 的全部文件与基准一致；版本号使用新的 2.0.5-r4，旧标签和历史发行保持可追溯。

## 恢复范围

- 持竿左键由原生近战流程判伤害，使用普通近战分类、向量与受击间隔；不会因手持鱼竿而改走鱼钩零伤害。
- 右键抛出的鱼钩按2.0.4进行零伤害 THROWN 受击，再处理一次经典KB；成功后立即发送速度并补方向性受击动画和声音。
- 鱼钩命中后保留钩与钓线，轻微回弹下落；每枚鱼钩只接触一次，收杆取消拉回。固定0.3碰撞余量、共同受击间隔恢复到基准实现。
- 恢复当时的 ClassicCombat、KnockbackListener、RodListener、RodVelocity、客户端包处理及启动接线。后加的 shared KB guard、native damage feedback、固定受击角度及 Leaf 第二次同步速度保护全部撤回，避免后续共用路径继续改变旧版行为。
- 2.0.4 已包含的贴身暴击方向修复、jump reset、stop_sprint、普通近战3.0距离、防互推和横扫音效/粒子屏蔽保留。

这是源码回退，不是以新机制模拟旧版。2.0.4 原有的限制也随之恢复：自定义profile/API取消导致原生回退时的反馈限制、Leaf第二次速度派发保护等后续修正不包含在此版。不能据源码相同保证所有核心、外部插件及客户端条件下的画面和手感相同。

## 配置与安装

配置数值、解析器和补全逻辑与2.0.4一致，模板仅更新版本说明。继续读取现有模式、profiles、玩家分配与向量；已有9/9/9 tick不会强制改为默认10 tick。有效间隔仍取配置共同下限，见[鱼竿保护说明](CLASSIC-ROD-STACK.md)。

1. 正常关闭服务器，备份现有插件Jar和数据目录。
2. 移除旧ModernKnockBack Jar，放入 `ModernKnockBack-2.0.5-r4.jar`。
3. 正常启动，用 `/mkb status` 确认版本为2.0.5-r4、模式为classic；不删除配置，也不使用热卸载。
4. 分别测试持竿左键近战、右键鱼钩、快速连续出杆和竿接刀，再确认重启后仍按原配置运行。

本地验证结果见[验证记录](VERIFICATION.md)。未部署线上服、未修改核心，真人受击反馈和手感需在目标服复测。
