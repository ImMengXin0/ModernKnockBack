# Origin

ModernKnockBack uses the category/profile design requested for the local KnockbackManager project (`me.dw1e.kbm`) as a functional reference. Its Minecraft 1.21.11 event pipeline, modern impulse processing, Folia scheduling and public API are implemented independently for this project. It does not include or modify the legacy plugin or ThePit core.

The accompanying GPL license is retained from the reference project. Minecraft, Paper, Folia, Leaf, ASPaper and KnockbackSync are separate projects; their server/plugin JARs are not bundled in this plugin artifact. Compatibility investigation uses their APIs and local server bytecode, not redistributed server implementations.
